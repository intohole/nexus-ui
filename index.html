为什么是 Nexus UI

为 CDN 应用而生，不为构建工具而生

01

零构建，两行接入

不装依赖、不搭脚手架，一行 CSS 一行 JS 即刻生效。全集群共享浏览器缓存，从第二个应用起，加载成本趋近于零。

02

27 套主题，一套组件

点右上角「主题罗盘」，整页即时换肤。每个应用只需一个 body class，主色与浅色、深色模式全部联动。

03

移动端适配收口

安全区、dvh、44px 触摸命中区、软键盘适配都在中间件完成，业务代码不写一行媒体查询。

04

生产级 API 客户端

重试、超时、取消、401 统一处理、CRUD 工厂、SSE 流式。AI 对话与 Markdown 安全渲染开箱即用。

05

版本统一收口

deps.json 是全工作区 CDN 版本的唯一事实来源，check_deps.py 一键校验，杜绝版本漂移。

快速开始

三步接入

1

引样式

nexus-all.css 包含全部组件样式与主题变量。

2

引 Vue 与组件脚本

用到哪个引哪个，也可以用 nexus-all.js 全量引入。

3

注册并使用

app.component('nux-button', NuxButton)，然后像写 HTML 一样使用。

<link rel="stylesheet"
      href="https://songguokr.com/nexus-ui/v2.10.53/css/nexus-all.css">
<script src="https://registry.npmmirror.com/vue/3.4.21/files/dist/vue.global.prod.js"></script>
<script src="https://songguokr.com/nexus-ui/v2.10.53/js/nexus-all.js"></script>
<script src="https://songguokr.com/nexus-ui/v2.10.53/js/components/nux-button.js"></script>

app.component('nux-button', NuxButton)
