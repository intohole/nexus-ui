# Nexus UI 配色系统规范

> 基于 Ant Design 系统级色彩体系 + WCAG 2.1 AA 标准 + 2025 现代 SaaS 设计趋势

## 设计价值观

色彩在 UI 中的态度是**克制**的：色彩服务于信息传递、操作引导和交互反馈，不破坏操作效率，不影响信息清晰传达。

## 色彩层级模型（三层）

```
1. 系统级色彩(本规范)
   └── 基础色板 + 中性色板 + 功能色板
2. 应用级主题(nexus-themes.css)
   └── 每个应用的 --app-accent 主色
3. 场景级使用(各业务页面)
   └── 通过 var(--nx-*) 引用语义变量
```

## 中性色板（10级灰阶，参考 Ant Design gray-0~9）

> 用于文字、背景、边框、分割线、禁用态。统一灰阶可避免"看起来差不多但实际不同"的视觉混乱。

| 级别 | 浅色模式 | 暗色模式 | 用途 | WCAG 对比度(浅色背景) |
|------|---------|---------|------|---------------------|
| gray-1 | #ffffff | #1a1a26 | 表面/卡片背景 | - |
| gray-2 | #fafafa | #22222e | 布局背景 | - |
| gray-3 | #f5f5f5 | #2a2a36 | 次级背景/禁用背景 | - |
| gray-4 | #d9d9d9 | #3a3a48 | 边框/分割线 | 1.4:1（仅装饰用） |
| gray-5 | #bfbfbf | #5a5a6a | 禁用文字 | 2.4:1（禁用态例外） |
| gray-6 | #8c8c8c | #8a8a9a | 占位文字/辅助说明 | 3.5:1（仅大字号≥18px） |
| gray-7 | #595959 | #a5a5b5 | 次要正文 | 5.7:1 ✓ AA |
| gray-8 | #434343 | #c5c5d5 | 正文 | 9.2:1 ✓ AAA |
| gray-9 | #0f172a | #f1f5f9 | 标题/重点文字 | 17.9:1 ✓ AAA |

## 文字色规范（透明度方案，参考 Ant Design）

> 使用透明度而非具体颜色，保证在任意背景上都自然过渡。深色模式用反向透明度。

| 场景 | 浅色模式 | 暗色模式 | 对应Hex(白底) | WCAG |
|------|---------|---------|--------------|------|
| 标题/一级文本 | #000000E0 | #FFFFFFD9 | #1f1f1f | 16.1:1 ✓ AAA |
| 二级文本 | #000000A6 | #FFFFFFA6 | #595959 | 7.6:1 ✓ AAA |
| 三级文本 | #00000073 | #FFFFFF73 | #8c8c8c | 4.6:1 ✓ AA |
| 禁用文字 | #00000040 | #FFFFFF40 | #bfbfbf | 2.3:1（禁用例外） |

## 边框与分割线

```css
/* 浅色模式 */
--nx-border-strong: #d9d9d9;        /* 一级边框 - 卡片/输入框 */
--nx-border-split: rgba(0,0,0,0.06); /* 分割线 - 列表分隔 */
--nx-border-light: rgba(0,0,0,0.04); /* 次级边框 - 表格内行 */

/* 暗色模式 */
--nx-border-strong: #424242;
--nx-border-split: rgba(255,255,255,0.08);
--nx-border-light: rgba(255,255,255,0.04);
```

## WCAG AA 对比度强制要求

| 元素 | 最小对比度 | 验证范围 |
|------|----------|---------|
| 正文文字(<18px) | ≥ 4.5:1 | 任何背景上 |
| 大字号文字(≥18px或≥14px粗体) | ≥ 3.0:1 | 任何背景上 |
| 输入框边框 | ≥ 3.0:1 | 与背景 |
| 焦点指示器 | ≥ 3.0:1 | 与相邻颜色 |
| 图标/按钮文字 | ≥ 4.5:1 | 与按钮背景 |
| 装饰元素(分割线) | 不要求 | - |
| 禁用态元素 | 不要求 | - |

### 应用主题色使用边界

主色 `--app-accent` 仅用于：
- ✅ 关键行动点（主按钮/链接）
- ✅ 操作状态高亮（选中态/激活态）
- ✅ 重要信息强调（计数/状态标签）
- ✅ 品牌元素（Logo/导航高亮）

主色**禁止**用于：
- ❌ 大面积背景（除浅色背景 #fffX 区域）
- ❌ 正文文字（用 --nx-text-body）
- ❌ 装饰性图形（用 --nx-text-muted）
- ❌ 错误/成功状态（用对应功能色）

## 操作动线设计原则（F型/Z型/纵向表单）

### 1. 列表页（F型动线）
```
[顶部导航 80px] ── 主操作(右上) ───
─────────────────────────
[筛选条] [搜索框]
─────────────────────────
[列表主体]    ← 用户视线F型扫读
  第1列 | 第2列 | ... | 操作列(右侧固定)
─────────────────────────
[分页(右下)]
```

### 2. 表单页（Z型动线）
```
[标题] ─────────────── [返回]
       ↘
        [字段1: 标签左 标签宽4字符]
        [字段2: 标签左]
        [字段3: 标签左]
                    ↘
                    [取消] [保存(主色)]
```

### 3. 详情页（纵向表单动线，移动端）
```
[顶部导航 ← 标题 ⋯]
─────────────────
[主信息块]
[次信息块]
[操作块(底部固定)]
```

### 4. 表单字段标签规则
- **左对齐标签**（默认）：标签宽度固定，输入框右对齐填满
- **顶对齐标签**（移动端）：标签在上，输入框占满宽度
- **内嵌标签**（搜索框）：仅用于单一搜索场景，禁止用于复杂表单

## 按钮层级规范

| 层级 | 样式 | 用途 |
|------|------|------|
| Primary | 主色填充 + 白字 | 每屏仅1个主操作 |
| Default | 白底 + 主色边框 + 主色字 | 次级操作 |
| Dashed | 虚线边框 | 添加/上传 |
| Text | 无边框 + 主色字 | 链接/弱操作 |
| Danger | 红色填充/边框 | 删除/危险操作 |

## 改造步骤（每个应用）

1. **审计现有配色**：grep 所有 hex 颜色，列出非标准颜色
2. **替换为语义变量**：硬编码颜色 → `var(--nx-*)` 引用
3. **验证对比度**：使用 WebAIM Contrast Checker 验证文字/背景组合
4. **移动端验证**：375px 宽度下检查触控目标≥44px
5. **暗色模式验证**：切换 `data-theme="dark"` 检查可读性
6. **Code Review**：人工检查操作动线是否符合规范
7. **端到端测试**：实际页面截图对比
